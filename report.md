# Отчёт: разработка прототипа байесовской сети на Go

## 1. Цель работы

Цель работы — разработать прототип байесовской сети на Go, проверить основные алгоритмы и оценить возможность использования готовых библиотек.

Модель описывает взаимосвязь между функциональным классом сердечной недостаточности (NYHA), уровнем циркулирующей ДНК (cfDNA), индексом вазоактивно-инотропной поддержки (VIS) и длительностью искусственной вентиляции лёгких (ИВЛ).

Программа загружает данные из CSV-файла или создаёт синтетическую выборку, обучает таблицы условных вероятностей и рассчитывает вероятность заданного исхода.

## 2. Выбор библиотек

Программа использует стандартную библиотеку Go. Дополнительные зависимости для работы с байесовскими сетями не подключаются.

| Пакет | Назначение |
|---|---|
| `encoding/csv` | Чтение данных из CSV |
| `flag` | Параметры командной строки |
| `math` | Математические расчёты |
| `math/rand` | Генерация синтетических данных |
| `strconv`, `strings` | Обработка значений CSV |
| `testing` | Автоматические тесты |

Самостоятельно реализованы граф сети, таблицы условных вероятностей, обучение и два алгоритма инференса.

В качестве альтернатив рассматривались `mlange-42/bbn` и `JohnPierman/bngo`, а также библиотеки `gonum` для математических вычислений и `gota` для работы с таблицами. Для текущей модели выбрана собственная реализация: сеть небольшая, поэтому её устройство и расчёты удобно контролировать напрямую.

## 3. Структура байесовской сети

В модели используются четыре бинарные переменные:

| Переменная | Состояния |
|---|---|
| NYHA | I–II, III–IV |
| cfDNA | низкий, высокий уровень |
| VIS | низкий, высокий уровень |
| IVL | до 24 часов включительно, более 24 часов |

Связи заданы заранее:

```text
NYHA → cfDNA
NYHA → VIS
cfDNA → VIS
cfDNA → IVL
VIS → IVL
```

Таким образом, cfDNA и VIS связаны с расчётом вероятности продолжительной ИВЛ, а NYHA влияет на распределения cfDNA и VIS в рамках заданной модели.

Граф создаётся в пакете `domain`, а его корректность проверяется средствами пакета `graph`, включая проверку циклических связей. Связи являются предположениями модели и сами по себе не доказывают причинно-следственные отношения между клиническими показателями.

## 4. Работа с данными

Программа поддерживает два режима.

- **Синтетические данные.** Выборка генерируется на основе заранее заданных вероятностей. Это позволяет сравнить обученные параметры с известными значениями.
- **Данные пациентов.** Программа читает CSV-файл с разделителем `;`, обрабатывает десятичные числа с запятой и пропущенные значения, включая `NaN`.

В текущем запуске используются следующие пороги:

- cfDNA от 50 нг/мл — высокий уровень;
- VIS от 5 — высокий уровень;
- ИВЛ более 24 часов — продолжительная вентиляция.

Пороги cfDNA и VIS можно менять при запуске. Пока их следует рассматривать как настройки прототипа, а не как утверждённые клинические нормативы.

В таблице пациентов было 52 наблюдения. Для обучения использовались только строки, в которых заполнены все четыре переменные: таких строк оказалось 34. Ещё 18 строк были исключены из-за пропущенных значений. В отчёте программы причины отображаются по первому обнаруженному пропуску в строке: `missing_cfdna: 13`, `missing_vis: 5`.

Другие показатели, включая возраст, массу тела, PGE1, долю мтДНК, острое повреждение почек, сепсис и летальность, в текущую сеть не включены.

## 5. Обучение модели

Обучение выполняется в пакете `learning`. Для каждой переменной рассчитываются условные вероятности с учётом значений её родителей в графе. Например, для VIS учитываются NYHA и cfDNA, а для IVL — cfDNA и VIS.

Используется сглаживание Дирихле с параметром `alpha`. При `alpha = 1` к частотам добавляются псевдосчёты, что уменьшает вероятность нулевых оценок для редких комбинаций. При `alpha = 0` используются обычные частоты без сглаживания.

Структура графа во время обучения не меняется: программа оценивает вероятности для заранее заданных связей.

## 6. Расчёт вероятностей

Основной запрос модели:

```text
P(IVL > 24 ч | VIS = high, cfDNA = high)
```

Он показывает, какую вероятность модель назначает ИВЛ длительностью более 24 часов при высоких значениях VIS и cfDNA.

Реализованы два алгоритма точного инференса:

- **Enumeration (полный перебор)** — перебирает возможные состояния скрытых переменных и суммирует соответствующие вероятности.
- **Variable Elimination (исключение переменных)** — объединяет промежуточные таблицы вероятностей и исключает ненужные переменные по мере расчёта.

После вычислений программа сравнивает ответы обоих алгоритмов. Совпадение с малой погрешностью машинной арифметики служит проверкой согласованности реализаций.

## 7. Результаты обучения на синтетических данных

Для проверки была сгенерирована выборка из 4000 наблюдений с параметрами `-n 4000 -seed 42 -alpha 1`. Поскольку исходные вероятности генератора известны, можно оценить, насколько точно модель восстановила их по выборке.

Максимальная абсолютная ошибка внутри каждой таблицы условных вероятностей составила:

| Таблица вероятностей | Максимальная абсолютная ошибка |
|---|---:|
| NYHA | 0,0069 |
| cfDNA | 0,0042 |
| VIS | 0,0415 |
| IVL | 0,0233 |

Для основного запроса результаты были следующими:

| Расчёт | Вероятность ИВЛ более 24 часов |
|---|---:|
| Обученная модель | 0,8411 (84,11%) |
| Исходная модель генератора | 0,8500 (85,00%) |
| Абсолютная разница | 0,0089 (0,89 процентного пункта) |

Enumeration и Variable Elimination дали одинаковый результат с точностью до погрешности вычислений: разница между ними составила примерно `2,78 × 10⁻¹⁷`.

Результаты показывают, что на этой синтетической выборке алгоритм восстановил параметры достаточно близко к исходным значениям. Ошибка зависит от размера выборки и случайного состава наблюдений; этот эксперимент сам по себе не подтверждает клиническую точность модели.

## 8. Результаты на данных пациентов

Для файла `data/patients.csv` программа обработала 52 строки. Из них 34 полные строки использовались при обучении, а 18 были пропущены из-за отсутствующих значений. Параметры запуска: `-alpha 1`.

Обученная таблица вероятностей для длительности ИВЛ:

| cfDNA | VIS | P(ИВЛ более 24 часов) |
|---|---|---:|
| Низкий | Низкий | 0,4118 (41,18%) |
| Низкий | Высокий | 0,5000 (50,00%) |
| Высокий | Низкий | 0,6667 (66,67%) |
| Высокий | Высокий | 0,9091 (90,91%) |

Таким образом, для основного запроса модель оценила вероятность ИВЛ более 24 часов при высоких cfDNA и VIS в 90,91%.

Это результат обучения на небольшой выборке, содержащей 34 полных наблюдения. Его нельзя трактовать как подтверждённый клинический риск или использовать для принятия медицинских решений без дополнительной проверки на более крупной и независимой выборке.

Enumeration и Variable Elimination на данных пациентов также совпали с точностью до машинной погрешности: разница составила примерно `1,11 × 10⁻¹⁶`.

## 9. Проверка программы

Для запуска автоматических тестов используется команда:

```bash
go test ./...
```

Последний запуск завершился успешно. Вывод Go:

```text
?    bnproto/cmd/bnproto    [no test files]
?    bnproto/cpt            [no test files]
?    bnproto/domain         [no test files]
ok   bnproto/graph          0.941s
ok   bnproto/inference      0.975s
?    bnproto/learning       [no test files]
ok   bnproto/patients       0.933s
?    bnproto/synthetic      [no test files]
```

Тесты успешно выполняются в пакетах `graph`, `inference` и `patients`. В пакетах `cmd/bnproto`, `cpt`, `domain`, `learning` и `synthetic` отдельные тестовые файлы отсутствуют. Поэтому не следует считать, что каждый компонент покрыт тестами.

Дополнительная проверка на синтетической выборке показывает, что два алгоритма инференса дают согласованные результаты, а обученная вероятность основного запроса близка к известной вероятности генератора. Это проверяет отдельные свойства реализации, но не заменяет независимую оценку качества прогноза.

## 10. Запуск программы

Из корневой папки проекта можно выполнить следующие команды:

```bash
# Синтетическая выборка
 go run ./cmd/bnproto -n 4000 -seed 42 -alpha 1

# Обучение на данных пациентов
 go run ./cmd/bnproto -csv data/patients.csv -alpha 1

# Автоматические тесты
 go test ./...
```

В первом режиме `-n` задаёт число синтетических наблюдений, `-seed` — начальное значение генератора случайных чисел, `-alpha` — сглаживание. Во втором режиме `-csv` указывает путь к таблице пациентов.

## 11. Ограничения и дальнейшая работа

У прототипа есть несколько ограничений:

- используются только четыре бинарные переменные;
- структура сети задаётся вручную;
- строки с пропусками исключаются из обучения;
- пороговые значения требуют отдельного клинического обоснования;
- выборка содержит только 34 полных наблюдения;
- качество прогнозов на независимых данных не оценивалось;
- автоматические тесты есть не во всех пакетах.

Дальнейшая работа может включать расширение сети другими клиническими показателями, сравнение результатов с готовой библиотекой байесовских сетей, анализ чувствительности к порогам и параметру сглаживания, а также изучение методов работы с пропущенными данными. Для оценки прогностического качества понадобится независимая выборка.

## 12. Вывод

Разработан прототип дискретной байесовской сети на Go без сторонних библиотек. Реализованы построение графа, обучение таблиц условных вероятностей, загрузка данных пациентов и два алгоритма точного инференса.

На синтетической выборке из 4000 наблюдений оценка вероятности продолжительной ИВЛ составила 84,11% при исходном значении 85,00%. На выборке пациентов из 34 полных наблюдений модель оценила эту вероятность в 90,91% при высоких cfDNA и VIS. Оба алгоритма инференса дали совпадающие результаты с точностью до машинной погрешности.

Команда `go test ./...` завершилась успешно: тесты прошли в пакетах `graph`, `inference` и `patients`. Полученные результаты подтверждают работоспособность основных проверенных частей прототипа, но не являются подтверждением его клинической точности. Для практического применения потребуется дополнительная проверка на более крупной независимой выборке.
